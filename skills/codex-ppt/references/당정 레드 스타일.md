# 당정 레드 스타일

**적합한 상황:** 붉은색 중심의 공식 행사, 공공·조직 보고, 기념·선포형 발표 등 사용자가 명시적으로 이런 시각 언어를 요청한 경우.

**시각 방향:** 레드와 골드를 제한적으로 사용하고 강한 제목 위계, 넓은 여백, 공식적인 대칭 구성을 적용하는 행사형 스타일.

```json
{
  "style_name":"당정 레드 스타일",
  "canvas":{"aspect_ratio":"16:9","background":"화이트 또는 딥 레드","density":"중간"},
  "color_palette":{"primary":"딥 레드","secondary":"화이트/웜 그레이","accent":"골드 소량","rule":"레드 면적과 골드 장식을 절제해 가독성을 우선"},
  "typography":{"title":"크고 단단한 산세리프 또는 명조 계열","body":"정돈된 본문","text_quality":"한글을 정확하고 선명하게 렌더링"},
  "layout_usage_rule":"표지·섹션 구분은 대칭성을 강화하고 일반 콘텐츠는 정돈된 1~2열 구조로 변주한다.",
  "visual_elements":{"allowed":"절제된 선, 공식 패턴, 큰 제목 블록","avoid":"과도한 장식, 복잡한 3D 효과, 내용과 무관한 상징"},
  "rendering_constraints":["공식적 인상을 유지하되 정보 전달을 우선한다.","사용자가 제공하지 않은 정치적 문구나 상징을 임의로 추가하지 않는다."]
}
```
