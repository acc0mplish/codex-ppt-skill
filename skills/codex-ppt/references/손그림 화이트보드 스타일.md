# 손그림 화이트보드 스타일

**시각 방향:** 실제 화이트보드에 마커로 정리한 듯한 자유로운 구성과 단순 아이콘을 사용한다.

```json
  "style_name":"손그림 화이트보드 스타일",

  "color_palette":{"primary":"블랙 마커","secondary":"블루","accent":"레드/그린 소량","rule":"마커 색을 제한해 가독성을 유지"},
  "typography":{"title":"굵고 자연스러운 필기형","body":"짧고 큰 문장","text_quality":"한글을 정확히 렌더링"},
  "layout_usage_rule":"자유로운 배치를 허용하되 시선 흐름은 화살표와 그룹으로 명확히 만든다.",
  "visual_elements":{"allowed":"마커 화살표, 원, 박스, 스틱 아이콘, 체크 표시","avoid":"사진, 복잡한 질감, 입체 효과"},
  "rendering_constraints":["화이트보드 느낌 때문에 정보 위계를 희생하지 않는다.","중요 문구가 겹치거나 잘리지 않게 한다."]
}
```
