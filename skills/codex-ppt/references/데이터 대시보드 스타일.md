# 데이터 대시보드 스타일

**적합한 상황:** KPI 보고, 운영 현황, 분석 결과, 데이터 중심 경영 보고.

**시각 방향:** 정돈된 지표 카드, 비교 차트, 상태 배지와 명확한 숫자 위계를 사용하는 현대적 대시보드형 스타일.

```json
{
  "style_name":"데이터 대시보드 스타일",
  "canvas":{"aspect_ratio":"16:9","background":"밝은 회색 또는 다크 네이비","density":"중간~높음"},
  "color_palette":{"primary":"네이비/블루","secondary":"시안/틸","accent":"상태별 그린·오렌지·레드 제한 사용","rule":"데이터 의미가 있을 때만 색을 부여"},
  "typography":{"title":"짧고 굵은 산세리프","body":"숫자와 라벨 중심","text_quality":"한글 라벨과 숫자를 정확히 렌더링"},
  "layout_usage_rule":"KPI 카드, 추세, 비교, 분포, 상세 근거 페이지를 섞어 같은 그리드 언어를 유지한다.",
  "visual_elements":{"allowed":"지표 카드, 막대/선 그래프, 상태 배지, 미니 차트","avoid":"의미 없는 3D 차트, 과도한 장식"},
  "rendering_constraints":["숫자와 단위를 가장 먼저 읽을 수 있게 한다.","차트 라벨과 범례를 생략하거나 왜곡하지 않는다."]
}
```
