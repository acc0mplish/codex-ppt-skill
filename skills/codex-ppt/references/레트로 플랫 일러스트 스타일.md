# 레트로 플랫 일러스트 스타일

**적합한 상황:** 제품 설명, 개념 소개, 문화·교육 콘텐츠, 친근한 스토리텔링.

**시각 방향:** 제한된 레트로 팔레트와 단순한 기하 형태, 평면 일러스트를 사용해 따뜻하고 기억에 남는 화면을 만든다.

```json
{
  "style_name":"레트로 플랫 일러스트 스타일",
  "canvas":{"aspect_ratio":"16:9","background":"크림/베이지 계열","density":"중간"},
  "color_palette":{"primary":"뮤트 블루/브라운","secondary":"올리브/크림","accent":"오렌지 또는 레드","rule":"채도를 절제하고 4~5색 안에서 운용"},
  "typography":{"title":"굵고 친근한 산세리프","body":"간결하고 큰 본문","text_quality":"한글을 또렷하게 유지"},
  "layout_usage_rule":"일러스트를 핵심 설명 도구로 쓰고 페이지 역할에 따라 좌우 분할, 중앙 장면, 단계형 구성을 변주한다.",
  "visual_elements":{"allowed":"평면 인물/사물, 단순 도형, 굵은 윤곽","avoid":"사실적 3D, 유광 효과, 과도한 그림자"},
  "rendering_constraints":["일러스트가 텍스트를 방해하지 않게 한다.","레트로 분위기와 현대적 가독성을 함께 유지한다."]
}
```
